# SLP Word Bank

A one-page site for speech-language pathologists that generates American English word lists.

- Choose how many words you want (1 to 500)
- Filter by syllable count, 1 to 10 syllables
- Every word is split into syllables **by pronunciation**, not spelling
- Every word is split into its phonemes
- General American IPA transcription with primary and secondary stress
- Optional: target a sound in initial, medial or final position
- Organize by syllable count, A to Z, or phoneme count, then copy, download as CSV, or print

It is a static site with no build step and no dependencies, so it runs anywhere that serves files.

## Publish on GitHub Pages

1. Create a new repository on GitHub, for example `slp-word-bank`.
2. Push the contents of this folder to the `main` branch.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
5. After a minute the site is live at `https://<your-username>.github.io/slp-word-bank/`.

## Preview locally

Opening `index.html` straight from disk will not load the word list (browsers block `fetch` on `file://`). Serve the folder instead:

```
npx serve .
```

or

```
python -m http.server 8000
```

## How the word list is built

`data/words.tsv` is generated by `scripts/build-data.mjs` (Node 18 or newer):

```
node scripts/build-data.mjs
```

Each line is `word`, `CMU pronunciation`, `frequency rank` (0 when the word is outside the top 50,000).
Syllable splits, phonemes and IPA are computed in the browser from the pronunciation.

| Source | Used for | License |
|---|---|---|
| [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) | Pronunciations and stress | BSD-style |
| [Moby Hyphenator](https://www.gutenberg.org/ebooks/3204) | Keeping real dictionary words, dropping names and abbreviations | Public domain |
| [FrequencyWords](https://github.com/hermitdave/FrequencyWords) | "Everyday" and "Common" familiarity levels | CC BY-SA 4.0 |
| [LDNOOBW list](https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words) | Excluding offensive words | CC BY 4.0 |

The same script writes `data/real-check.txt`: every spelling from CMU, Moby (names
included) and FrequencyWords, then every CMU pronunciation with stress removed. The page
loads it only when nonsense words are requested, and rejects any nonsense word whose
spelling or sounds match an entry.

`scripts/long-words.tsv` adds a few hand-transcribed 9 and 10 syllable words, because the
dictionary has almost none. Words of 7 or more syllables from CMU are kept even when Moby
lacks them, since they are real words (mostly medical and technical) rather than names.

### Transcription rules

- Syllables follow the maximal onset principle: consonants between two vowels start the
  next syllable as far as a legal English onset allows (`monster` → /ˈmɑn.stɚ/).
- A stressed lax vowel (/ɪ ɛ æ ʌ ʊ/) cannot end a syllable, so it keeps one consonant
  (`rabbit` → /ˈɹæb.ət/, `butterfly` → /ˈbʌt.ɚˌflaɪ/).
- /ʌ/ and /ɝ/ for stressed central vowels, /ə/ and /ɚ/ for unstressed.
- /ˈ/ and /ˌ/ go before the stressed syllable and replace the syllable dot. One-syllable
  words carry no stress mark.
- The r sound is /ɹ/ by default; a checkbox switches it to /r/.
